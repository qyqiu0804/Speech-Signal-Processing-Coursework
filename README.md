# Speech Signal Processing GUI

A MATLAB GUI for basic speech signal processing and digital filtering.

## Features

- Record and play speech signals
- Time-domain waveform visualization
- Frequency-domain analysis using FFT
- Gaussian noise simulation
- Ideal low-pass filtering
- Non-ideal low-pass filtering
- Nonlinear noise reduction
- Visualization of filtered signals and spectra

## Files

- `gui01.m` – Main MATLAB GUI and signal processing functions
- `gui01.fig` – GUI layout
- `README.txt` – Original usage instructions

## Requirements

- MATLAB
- Signal Processing Toolbox
